# 🔧 Git & GitHub for DevOps

This repository contains my **Git & GitHub notes and practicals** used in DevOps.

## 📚 Topics Covered

- Source Code Management (**CVCS vs DVCS**)
- Git Basics, Setup, and Workflow (**Add, Commit, Push, Pull**)
- Git Stages (**Workspace, Staging Area, Repository**)
- Branching, Merging, Stash, Reset, and Revert
- GitHub Usage (**Clone, Remote Repository, Collaboration**)
- Important Concepts (**.gitignore, Tags, Logs**)

## 🎯 Purpose

To understand **Version Control** and manage code efficiently in real-world **DevOps projects**.
